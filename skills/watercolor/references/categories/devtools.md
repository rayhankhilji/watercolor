# Playbook: Developer tools

Developers detect marketing instantly and reward craft, speed and honesty.

## What great looks like
- **Code is imagery**: real snippets, terminals, CLIs, API responses — set in a good mono (Geist Mono, JetBrains Mono, Berkeley Mono, the brand's own).
- **Monochrome or near-monochrome** with one accent; dark mode as a first-class theme.
- **Grid and geometry**: 1px lines, visible structure, technical diagrams — systems that look engineered.
- **Docs are the brand**: the docs site's type, code blocks and callouts matter as much as the homepage.
- **Speed in the motion**: snappy 100–200ms, no theatrical transitions.

## Traps
- Marketing-speak ("revolutionize your workflow").
- Fake code screenshots with syntax errors or lorem-ipsum identifiers.
- Overly rounded, bubbly UI that reads consumer.
- Neon-on-black "hacker" clichés unless genuinely the brand.

## Voice
Peer-to-peer, terse, exact. Imperatives ("Deploy in seconds"), concrete numbers (ms, regions, stars), dry humor allowed. Lowercase or sentence case. Commands formatted as code.
