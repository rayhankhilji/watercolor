# Examples

Five real brands run end to end: `watercolor extract` → agent-written `strategy.json` (by Claude, following the skill) → `watercolor build`. Each folder holds the generated **WATERCOLOR.md**, the **strategy.json** and a few downscaled previews. Full kits (fonts, captured media, every asset) aren't committed — run watercolor yourself to get them.

| Brand | Category | What watercolor picked up |
|---|---|---|
| [Stripe](stripe/) | Fintech infrastructure | Söhne Light, `#533AFD` CTAs (and the legacy `#635BFF`), two-tone ink/slate headlines, blue-tinted layered shadows, easeOutCubic at 150/300ms, the WebGL ribbon gradient recorded via `captureStream` with 25 shader sources |
| [Notion](notion/) | AI workspace | Inter 700 at −0.035em (`NotionInter` alias resolved), Lyon Text for quotes, warm `#F6F5F4` paper, Notion Blue as the only action color, flat — no gradients invented |
| [Plot](plot/) | Video social listening | Cream (not the pink panel), oxblood `#800532` + honey, Good Sans display at 150px+, GSAP ScrollTrigger, Lottie + 8 product videos |
| [Littlebird](littlebird/) | AI assistant with memory | Ink-led brand (black pill CTAs, green as accent), Meraki serif + Söhne, official press-kit logos downloaded, eggshell paper |
| [Wispr Flow](wisprflow/) | Voice dictation | EB Garamond with italic turns, lavender CTA, forest green bands, stitched full-page capture of GSAP-revealed content |

> Logos, names, fonts and imagery shown in these examples belong to their respective owners and are included only to demonstrate the tool's output.
